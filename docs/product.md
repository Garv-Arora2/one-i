# ONE I Product Specification

## Definition
ONE I is a news-reading and media-accountability platform that helps a user understand an event without relying on one outlet's presentation.

## Core principle
**Show the user the differences. Let the user decide.**

The product presents evidence and measurable differences rather than unsupported judgments.

## Primary user
A person who wants to become well-informed about a news event without manually reading and comparing many sources.

## Core journey
Landing -> Homepage -> Event -> Crux -> Context -> Timeline -> Coverage -> Wording + Numbers -> Public Reaction -> Sources. (Market impact is planned for V2.)

## V1
1. Crux + context
2. Timeline
3. Numbers
4. Wording/framing differences
5. Event coverage
6. Covered by / not covered by
7. Simple media coverage overview
8. Simple public reaction
9. Original source links
10. Google login + CAPTCHA

## V2
- Relevant market impact (backend groundwork exists; not shown in V1)

## Event-centric model
The primary object is an event, not an article. Articles from different sources are attached to the same event where appropriate.

## What ONE I is not
ONE I is not a truth engine, bias detector, propaganda detector, intent detector, fake-account detector, or autonomous AI news analyst.

## Success criteria
A user can understand what happened, its context and timeline, see meaningful source differences, inspect coverage, access original sources, and form their own judgment.
